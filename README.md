# Weather & Climate Insight Dashboard

This project is an dashboard that visualizes weather and climate data using the OpenWeatherAPI.  
Built using **PyCharm** & **Flask**, the app will display forecasts, climate trends, and educational insights.  


## Week 2 Progress
✅ Added `/weather` route in Flask to handle search requests  
✅ Integrated OpenWeather API for live weather data 
✅ Displayed city name, temperature, humidity, and condition icon dynamically  
✅ Implemented error handling and Flask logging for missing keys or bad input  
✅ Improved CSS styling and layout for a somewhat more responsive user interface
